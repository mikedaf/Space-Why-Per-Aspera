Space Why's own files are licensed CC BY-ND 4.0 (`LICENSE`). Some files inside Space Why come from other people. They keep their own license, and nothing in Space Why's license changes that. This file lists each group, who made it, its license, and whether Space Why changed it. The license texts are in the `licenses/` folder next to this file (inside the mod jar: `META-INF/licenses/`). Every mod the pack needs is downloaded from its own page (see CREDITS.md). Four of them ship as unchanged jars in the CurseForge zip, see the end of this file.

This list is made by comparing every file in Space Why with the same path in every mod of the pack.
